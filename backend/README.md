# 🚀 Task Manager Application

A full-stack Task Manager application that allows users to manage their daily tasks efficiently with authentication and advanced features.

---

## ✨ Features

- 🔐 User Authentication (Register & Login)
- ➕ Create Tasks
- ✏️ Update Tasks
- 🗑️ Delete Tasks
- 🔍 Search Tasks
- 🎯 Filter by Status (Pending, In Progress, Completed)
- 📄 Pagination
- 🎨 Clean and Responsive UI

---

## 🛠️ Tech Stack

### Frontend
- Next.js
- React
- CSS (Custom Styling)

### Backend
- Node.js
- Express.js
- MongoDB

### Other
- JWT Authentication
- REST API
