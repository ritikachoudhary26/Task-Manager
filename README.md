📌 Project Overview
This is a full-stack Task Manager web application that allows users to manage their daily tasks efficiently. The app includes authentication and complete CRUD functionality for tasks.

✨ Features
🔐 User Authentication (Register & Login)
📝 Create Tasks
📋 View All Tasks
✏️ Update Tasks
❌ Delete Tasks
🔒 Secure API using JWT Authentication
📱 Responsive UI
🛠️ Tech Stack

HTML, CSS
Backend:
Node.js
Express.js

MongoDB
Deployment:
